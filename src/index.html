About

Six years from server rooms to the cloud

That has meant on-premises servers and virtualisation, enterprise Active Directory, and now Azure, identity and DevOps. Day to day I provision with Terraform, ship through Azure DevOps, help deploy in-house software in Docker containers, and watch how it behaves in Datadog.

Most of my work has been in business-critical, regulated environments where a bad change is expensive, so I've learned to test first, write things down, and ask before assuming. I don't know everything about cloud and I'm fine saying so. I learn quickly, I finish what I pick up, and I'd rather ask a colleague a short question than guess for an hour.

Outside work you'll usually find me doing sports or building something small for the web.

Projects

Things I've built and run

Azure · Terraform · IoT · Observability

ChargeNet

A working miniature of the cloud platform behind an electric truck charging network. Simulated stations report over MQTT to IoT Hub; a processor moves telemetry into Log Analytics; alerts fire when a station faults or goes silent; a public status site and dashboard show it live.

  • Landing zone with Azure Policy guardrails, budgets and a hub-spoke network
  • Least privilege: OIDC pipelines and managed identities, no stored client secrets
  • Environment vending: one Terraform module per environment, platform-owned networking
  • Delivered by pull request: plans posted on PRs, protected main, nightly drift checks
  • Decisions recorded as ADRs, from public exposure to shared ingestion
